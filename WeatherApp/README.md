
# Weather App


## Introduction

Weather App is a simple, user-friendly web application that provides real-time weather information for locations worldwide. The application offers the following features:

- Current weather conditions display
- Temperature in Celsius/Fahrenheit
- Humidity and wind speed information
- Weather forecast visualization
- Location-based weather detection
- Search functionality for any city or region
- Responsive design for all devices

## How to Use

1. **Access the Application**
   - Open the application in any modern web browser
   - Allow location access when prompted for automatic local weather

2. **Search for Weather**
   - Use the search bar to enter a city name
   - Press Enter or click the search icon to get weather information

3. **View Weather Details**
   - See current temperature, conditions, and other metrics
   - Toggle between Celsius and Fahrenheit if available
   - View additional information such as humidity and wind speed

4. **Save Preferences**
   - The app remembers your last searched location for convenience
   - Settings are preserved between sessions

## Tech Stack

This application is built using pure frontend technologies, allowing it to run entirely in the browser without any backend requirements:

- **HTML5** - For structure and content
- **CSS3** - For styling and responsive design
- **JavaScript** - For dynamic functionality and API integration
- **Cookies** - For storing user preferences and recent searches
- **Weather API** - Openweather API version 2.5 (free) for fetching real-time weather data

No installation or server setup is required to run this application.
