# Audio Files for Pop-It Game

Place the following audio files in this directory:

1. `pop.mp3` - Sound effect for popping bubbles
2. `win.mp3` - Sound effect for when the game ends
3. `background.mp3` - Background music that loops during gameplay

## Recommended sources:

- You can find royalty-free sound effects on websites like Freesound.org, SoundBible, or ZapSplat
- For background music, consider cheerful, child-friendly tracks from sites like Pixabay Music or Bensound
- Ensure all audio files are in MP3 format for maximum browser compatibility

## Audio file specifications:

- `pop.mp3`: Short (0.5-1 second) popping sound
- `win.mp3`: 2-5 second celebratory sound
- `background.mp3`: 1-2 minute looping track, upbeat and kid-friendly
