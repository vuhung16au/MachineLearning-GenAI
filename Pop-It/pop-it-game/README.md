# Pop-It Game

## Overview
The Pop-It Game is a fun and interactive web-based game designed for kids. The objective of the game is to pop all the buttons on the heart-shaped game board before your opponent does. The game can be played against a computer opponent or with a friend.

## Project Structure
```
pop-it-game
├── index.html          # Main HTML file for the game
├── css
│   └── style.css      # Styles for the game
├── js
│   ├── game.js        # Main game logic
│   └── audio.js       # Audio handling
├── assets
│   ├── audio
│   │   ├── pop.mp3    # Sound effect for button press
│   │   ├── win.mp3    # Sound for game end
│   │   └── background.mp3 # Background music
│   └── fonts
│       └── game-font.ttf # Custom font for the game
└── README.md          # Project documentation
```

## Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, etc.)
- Basic understanding of HTML, CSS, and JavaScript (optional)

### Installation
1. Download or clone the repository to your local machine.
2. Open the `index.html` file in your web browser to start the game.

### How to Play
- Click on the buttons on the heart-shaped board to pop them.
- The game can be played in two modes: against a computer opponent or with a friend.
- The player who pops all the buttons first wins the game.

### Audio Files
- Place the audio files in the `assets/audio` directory.
- Ensure that the audio files are named correctly as specified in the project structure.

### Customization
- You can customize the styles by editing the `css/style.css` file.
- To change the game logic, modify the `js/game.js` file.
